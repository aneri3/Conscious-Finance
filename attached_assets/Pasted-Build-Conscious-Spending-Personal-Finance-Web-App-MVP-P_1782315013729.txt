Build: "Conscious Spending" — Personal Finance Web App (MVP Prototype)Product contextBuild a web app for young Indian professionals that tracks spending against a "Safe Limit" instead of a strict budget. Core philosophy: awareness, not restriction. The hero metric is "how much of my Safe Limit is left this month" — when the user crosses it, they enter a "Red Zone" state (a gentle warning, not a block).This is a working prototype, not the production app — bank connectivity via India's Account Aggregator framework will be wired in later. For now, the app features a first-run onboarding wizard that captures income, Safe Limit %, and data source preference. It builds a dual-mode path: either a mocked AA background synchronization or a live, robust CSV statement parser. Both paths feed a single shared categorization pipeline. It also includes a global logout/reset switch to let testers cleanly jump between modes without database collision.Tech stackFrontend: React + TypeScript, Vite, Tailwind CSSBackend: Node.js + Express + TypeScript (single repo, REST API)Database: PostgreSQL (use Replit's built-in Postgres)No auth system needed yet — a single hardcoded demo user row is fine for this prototype.Database schemaCreate these tables in Postgres (adapt types as needed for your ORM/driver, Drizzle or Prisma are both fine — pick one and be consistent):users: id (UUID), full_name, monthly_income (numeric, nullable), safe_limit_pct (numeric, default 40.00), data_source_mode (TEXT enum: 'AA_MOCK', 'CSV_UPLOAD', nullable).
